The task

The model knows each atomic number. The question asks for their sum.

Two ways to answer

Both final replies get the same instruction: “Reply with the answer only: one number.”

  1. Direct. The model gets the question and replies at once. 1 request.
  2. Self-querying. Step 1: the model writes one short question and answer for each element, for example “What is the atomic number of Fe? 26”. Step 2: it gets the question with these notes in its context, and replies. 2 requests.
2 to 6 symbols.
Reasoning effort
With low, hidden reasoning can recall the facts too.

Result

Code reads the number in each reply and compares it with the periodic table.

Each run

What the model got and what it wrote, step by step. Run 1 of each mode is open.

Second check

After the runs, a second model (a grader) reads each run and finds its final number and the facts before it. Code compares this with the result above.
