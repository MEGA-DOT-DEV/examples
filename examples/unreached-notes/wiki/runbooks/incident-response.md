# Incident response

1. Open a thread in #incidents with one line: what is broken, since when.
2. Page the primary on call if customers are affected.
3. Name one person as the lead. Everyone else helps the lead, not the thread.
4. Post an update every 30 minutes, even if nothing changed.
5. Write a short report within a week: timeline, cause, what we change.
