# Deployment: a history of our tools

- 2021: one server, and a shell script that copied files over SSH.
- 2022: Docker images and a manual "promote" button in the hosting console.
- 2023: CI builds an image for every merge to main.
- 2024: `shipctl`, our own small CLI, replaced the promote button. The edge router came with it.
- 2025: the dashboard for tags and errors (see the redesign project).
