Do two Workers in one checkout keep each other's edits?

Two Workers change different rules in the same file, first in one shared checkout, then in one Git worktree each. Tests count the edits that survive.

An edit is kept when the Worker saved it and its own test passes in its checkout or branch.

Save by save

Each save runs both tests. A red mark shows a save that broke the other Worker's passing test.

Inputs

Both modes use the same tasks and start from the same quote.js. Each run makes a temporary local repository and deletes it at the end.
