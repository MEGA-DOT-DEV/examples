# Receipts before effects: idempotency keys for agent tool calls

Synthetic lab content. This is not an actual arXiv paper.

An agent that calls a tool with an outside effect must write the receipt key before the effect, not after it. If the process dies between the effect and the record, a retry with the same key lets the outside service return the first result instead of acting twice.

We measure 1,200 crash points in a mail-sending agent. With the key written first, no crash point produced a second email. With the key written after the effect, 7% of crash points did.

The key must name the intent, not the attempt: a retry is the same intent, so it carries the same key.
