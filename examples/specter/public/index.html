Specter.

Specter watches what the user saves and edits in their notes, decides what matters with a cheap first look, keeps its own agenda, and writes back quietly. It has no chat window and no command words.

This page is a lab. Start a simulation of the user’s day, watch each step, and break it safely. Every time on the page reads +m:ss from the start of the simulation.
