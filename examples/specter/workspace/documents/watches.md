# Watches

What my first look should watch for, in plain language. I write and prune these myself, and each one says why. The first look reads them with the user's focus and still judges each batch: a watch is a reason to look closer, not a rule.

- A paper or link the user saves that meets their focus (durable runs, receipts): worth a run to read it and write a linked note, because a fresh save is when the connection helps them most.
- The user edits, deletes, or links one of my notes, or replies to a digest: worth a run soon, because what they did with my work is the lesson.
